# Community Services Management System

## C++ / Drogon Implementation

This repository contains the C++ implementation of the Community Services Management System (CSMS) for the Programming Languages Laboratory.

The project will be developed incrementally throughout the semester using sprint-based activities and Git-based development practices.

## Technology Stack

- Language: C++
- Framework: Drogon
- Build Tool: CMake
- Testing: CTest
- Configuration: JSON / YAML
- Version Control: Git and GitHub

## Current Version

0.1.0

## Current Sprint

Sprint 0 – Developer Onboarding

## Project Goal

The Community Services Management System is a semester-long software project designed to demonstrate how the same application requirements can be implemented using different programming languages and frameworks.

Students will gradually implement application functionality through assigned development tickets.

## Starter Application

The starter application provides:

- a working Drogon application;
- a home route;
- a health endpoint;
- starter controllers;
- project structure placeholders;
- automated build configuration;
- automated tests;
- Git workflow documentation.
